# VALO-STRIKE // PROTOCOL 07

A browser-based 3D tactical shooter inspired by Valorant, built with Three.js and PeerJS.

## Features

- True 3D weapon models (Three.js WebGL)
- Wall-occluded bot AI
- Physics-based projectile abilities
- P2P 1v1 multiplayer via PeerJS
- 144+ FPS target
- FPP / TPP camera modes
- 3 playable agents: VEX, SAGE-09, SOVA-X
- 4 game modes: Spike Site Assault, FFA Deathmatch, Practice Range, Radianite Survival

## Controls

| Key | Action |
|-----|--------|
| WASD | Move |
| Mouse | Aim |
| LMB | Fire |
| RMB | Scope / ADS |
| R | Reload |
| V | Toggle FPP / TPP |
| C / Q / E / X | Abilities |
| 1 / 2 / 3 | Switch weapon slot |
| B | Buy Menu |
| 4 (Hold) | Plant Spike |

## Tech Stack

- [Three.js r128](https://threejs.org/)
- [PeerJS 1.5.2](https://peerjs.com/)
- Vanilla JS / HTML / CSS — no build step required
